Conexão dos caixas

Exportar conexão (.hubconn)

O arquivo .hubconn leva o endereço HTTPS, o certificado público da loja e a credencial do agente — não leva o token do Telegram nem a senha administrativa. Importe-o na janela de cada computador monitorado. Compartilhe apenas com quem está autorizado a instalar o monitor.

Destino fiscal da loja

Informe o endereço que a loja realmente usa. O sistema não presume endereços de outras UFs: confirme com a SEFAZ ou o contador.

Alertas pelo Telegram

Use o token criado pelo BotFather. O ID numérico do bot será mostrado após o teste; para enviar mensagens, o campo necessário aqui é o ID do grupo. Adicione o bot ao grupo antes de testar.

MikroTik (opcional, somente leitura)

Crie no MikroTik um usuário restrito às permissões read, api e test. Esta integração consulta dados e não altera a configuração do roteador.
